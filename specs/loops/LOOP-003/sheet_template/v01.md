LOOP-003 §3 — the feedback sheet, version 1.

This is the object the loop improves. The format is fixed and the validator
(`validate-sheet.mjs`) refuses an incomplete one: an unsent sheet is a bug
caught, a half-filled sheet is a redraft wasted.

Substitute the bracketed slots. Keep every heading, in this order, including
the ones that come out empty — the writer needs to see that RESOLVED is empty
as much as it needs to see what is in it.

What changes between versions is wording, order of blocks, and above all how
"HOW IT SHOULD READ" is phrased, because that is where this loop learns. What
never changes is that all five scores appear, that every finding carries its
four fields, and that nothing is trimmed to make the sheet shorter.
-->
